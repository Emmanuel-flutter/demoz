# brand-input

This is step 1 of onboarding. Put your brand media here.

Drop in:

- Your logo. A transparent PNG or SVG is best.
- Your brand media for colour extraction.

## Which media gives the best colours

A brand-guidelines page gives the best colours. A marketing screenshot or a
product screenshot also works well. These show the real palette in use.

A bare logo often has no usable palette. A logo can have only one or two
colours. It can also be a single flat colour. Do not rely on a bare logo alone.

## What happens next

1. You tell the agent where this folder is.
2. The agent reads the media in this folder.
3. The agent proposes a contrast-checked palette.
4. You review the proposal and approve it.
5. The agent saves the profile to `src/theme.ts`, `src/fonts.ts`, and the logo.

See the `demoz-skill` SKILL.md for the full 3-step onboarding.

## Note

Git ignores the files you add here. Git keeps this README only. Your brand
media stays local to your machine.
